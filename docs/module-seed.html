Module: seed

This script reads JSON files containing movies, genres, and users data and populates the MongoDB database. It clears existing data before seeding to ensure a clean state. Run this script with: node seed.js

Methods

(async, inner) seedData() → {Promise.<void>}

Performs the following operations: 1. Connects to MongoDB using the URI from environment variables 2. Clears all existing movies, genres, and users from the database 3. Reads data from movies.json, genres.json, and users.json 4. Inserts the data into their respective collections 5. Closes the database connection
