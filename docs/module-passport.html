Type Definitions

callback(username, password)

Authenticates users with username and password credentials. Includes validation to prevent NoSQL injection attacks by checking username format.
Parameters:
Name Type Description
username string User's username (alphanumeric only)
password string User's password
callback.error Error | null Error object if authentication fails
callback.user Object | boolean User object if successful, false if failed
callback.info Object Additional info object with error messages

// Usage in route
passport.authenticate('local', { session: false }, (err, user, info) => {

callback(jwtPayload)

Authenticates users via JWT tokens extracted from the Authorization header. Validates the token's user ID before attempting database lookup.
Parameters:
Name Type Description
jwtPayload Object Decoded JWT payload
Properties
Name Type Description
_id string User's MongoDB ObjectId from the token
username string User's username from the token
callback.error Error | null Error object if authentication fails
callback.user Object | boolean User object if successful, false if failed
